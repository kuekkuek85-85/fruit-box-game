# 🍎 사과 게임 (Fruit Box) — 교실용 웹앱

중학교 정보 수업용 "합이 10" 사과 퍼즐 게임 + 교사용 대시보드.
17×10 보드의 사과를 드래그해 합이 정확히 10이 되면 지우고, 학번·성명으로
기록을 집계합니다. ([PRD](#) 기반 MVP 구현)

빌드 도구·프레임워크 없이 **순수 HTML/CSS/JS** 로 만들어, 정적 호스팅
(Vercel·Netlify·GitHub Pages)에 그대로 올리면 됩니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 학생용 — 식별 → 게임 → 결과 |
| `dashboard.html` | 교사용 — 집계·순위·CSV·초기화 |
| `js/game.js` | 게임 핵심 로직(보드·드래그 판정·점수·타이머·힌트) |
| `js/student.js` | 학생 화면 흐름 |
| `js/dashboard.js` | 교사 대시보드 |
| `js/storage.js` | 저장소 추상화(localStorage ↔ Firebase 자동 전환) |
| `js/firebase-config.example.js` | Firebase 설정 예시(복사해서 사용) |

## 바로 실행

설치 없이 로컬 서버만 있으면 됩니다(`file://` 로 열면 일부 브라우저에서
터치/보안 제약이 있어 서버 권장):

```bash
# 프로젝트 폴더에서
python3 -m http.server 8000
# 브라우저에서
#   학생   → http://localhost:8000/index.html
#   교사   → http://localhost:8000/dashboard.html   (기본 비밀번호: teacher)
```

## 게임 규칙

- 17열 × 10행, 사과 숫자 1~9, 총 170개.
- 드래그로 **직사각형** 영역을 선택 → 영역 안 남은 사과의 합이 **정확히 10**이면
  지워지고, 지운 개수만큼 득점.
- 빈칸은 0으로 계산(지운 칸을 가로질러 연결 가능), 사과는 이동하지 않음.
- 제한 시간 90/120/180초 선택, 170점이면 퍼펙트 클리어.
- 마우스·터치 모두 지원.

### 보조 기능
힌트(판당 2회), 일시정지, 새 보드(클래식), 효과음 on/off, 연한 색상 모드(색약 배려).

### 모드
- **클래식**: 매번 새 보드.
- **공통 보드(수업용)**: 같은 보드를 전체 학생이 플레이. 교사가 대시보드의
  "공통 보드 설정"에서 보드 번호를 지정(비우면 날짜 기반 자동값).

## 교사 대시보드

- 학생별 기록 테이블(학번·성명·학년/반/번호·최고점·횟수·최근 플레이) — 정렬·필터·검색.
- 실시간 순위(동점 시 소요 시간 빠른 순), 반별 평균·최고·참여, 점수 분포.
- CSV 내보내기(엑셀 한글 BOM 포함), 기록 초기화(차시 정리용).
- 학번 5자리 = 학년(1) + 반(2) + 번호(2) 자동 분해. 학교별 체계가 다르면
  `js/storage.js` 의 `parseStudentNo` 만 수정하면 됩니다.

## 데이터 저장 — 2단계 접근

**1단계(기본, 설정 불필요):** `firebase-config.js` 가 없으면 이 기기의
`localStorage` 에만 저장됩니다. 단일 기기·공용 기기에서 게임성과 UX를 바로
검증할 수 있습니다. 같은 기기의 다른 탭(교사 대시보드)에는 실시간 반영됩니다.

**2단계(학급 집계):** 여러 기기 기록을 모으려면 Firebase Firestore 를 붙입니다.

1. `js/firebase-config.example.js` → `js/firebase-config.js` 로 복사.
2. 본인 Firebase 프로젝트 값으로 교체(콘솔 → 프로젝트 설정 → 웹 앱).
3. Firestore 생성 후 수업용 보안 규칙 설정.

설정이 있으면 `storage.js` 가 자동으로 Firebase 백엔드로 전환하고, 대시보드는
`onSnapshot` 으로 실시간 집계합니다. 초기화 실패/네트워크 불안정 시 결과는
자동 재시도(0.5s·1s·2s) 후 "다시 저장" 버튼을 제공합니다.

> 보안 규칙 예시(수업용, 교내 한정 권장):
> ```
> rules_version = '2';
> service cloud.firestore {
>   match /databases/{db}/documents {
>     match /gameRecords/{id} {
>       allow read, write: if true;  // 교내 수업용. 공개 배포 시 반드시 강화하세요.
>     }
>   }
> }
> ```

## 개인정보

학번·성명만 최소 수집하며 수업 목적에 한정합니다. 외부 공개 순위표·계정 없음.
차시 종료 후 대시보드에서 손쉽게 초기화할 수 있습니다.

## 알려진 한계 / 후속(PRD 로드맵)

- 보드 생성은 전체 합을 10의 배수로 맞추지만, "반드시 전부 지울 수 있는" 완전
  해결 가능성까지 보장하지는 않습니다(힌트·새 보드로 보완). 구성형 생성기는 후속 과제.
- 교사 대시보드 비밀번호는 클라이언트 측 게이트입니다(학생 접근 차단 용도).
- 차시별 세션 분리, 학급 대항전, 배지, 개인 성장 그래프 등은 후속 확장 항목입니다.
